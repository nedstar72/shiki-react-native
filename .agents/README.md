# Инструкция для агентов

Этот файл служит входной точкой для AI-агентов и фиксирует актуальные договорённости проекта.

## Первичный набор действий

Перед началом любой работы:

1. Изучите `.agents/RULES.md` — здесь собраны базовые правила работы с проектом.
2. Изучите `.agents/docs/INDEX.md` — здесь описана базовая информация о реализованном функционале.
3. Изучите `.agents/PROJECT.md` — здесь зафиксированы особенности окружения и ключевые команды проекта.
4. Ознакомьтесь с `.agents/FLOW.md` — здесь описан порядок взаимодействия между агентом и оператором.

## Структура .agents

- `RULES.md` — базовые правила проекта, которые всегда необходимо учитывать.
- `FLOW.md` — порядок взаимодействия агента и оператора.
- `docs/` — проектная документация с описанием реализованного функционала.
- `docs/INDEX.md` — стартовая точка документации.
- `docs/MAINTAINING.md` — правила ведения документации.

# Справка по проекту

Этот файл кратко описывает проект и его структуру.

## Что это за проект

Мобильный клиент Shikimori на React Native + Expo под iOS/Android.

## Верхнеуровневая структура

- `src/app` — корневой слой приложения: композиционный корень, DI-контейнеры, экраны и виджеты верхнего уровня.
- `src/features` — доменные фичи (например, авторизация, каталог аниме) и их бизнес-логика.
- `src/shared` — общие блоки: DI-движок, навигационные утилиты, клиент Shikimori API, темы, UI kit и хелперы.
- `tools/graphql` — схема и конфиг генерации GraphQL-типов/клиента.
- `assets` — иконки, сплэши и прочие ресурсы.
- `ios` / `android` — нативные проекты для сборки и настройки платформ.
- `types` — глобальные типы.
- `e2e` — Detox-тесты и конфигурация.

# Ключевые компоненты

## DI-движок

- Обёртка над Inversify с классами `Container` и `Module` для декларативной регистрации зависимостей.
- Декораторы `@provide` и `@resolve` описывают фабрики и получение зависимостей, поддерживая общие области жизни и делегирование к родителю.

## Интеграция с React Native

- Слой `di-react-native` пробрасывает контейнеры в React через провайдер реестра, хранит их по ключам навигации и очищает при размонтировании экранов.
- Доступ к зависимостям из компонентов идёт через `withContainer`, `useDependency`, `useOptionalDependency` и контекст `ContainerProvider`.

## Композиционный корень приложения

- При старте создаётся корневой контейнер, который загружает модули фич и инфраструктуры.
- Навигация и UI оборачиваются в провайдер контейнеров, чтобы наследовать зависимости и передавать параметры экранов в конструкторы контейнеров.

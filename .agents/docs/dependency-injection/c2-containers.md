# Контейнеры и потоки

## Контейнеры

- Корневой контейнер создаётся при старте приложения и загружает фичевые модули.
- Дочерние контейнеры могут создаваться для экранов или виджетов: по умолчанию наследуют зависимости от родителя и могут расширять состав локальными сервисами.

## Основные потоки

- Композиция: корневой контейнер загружает модули фич и инфраструктуры.
- Раздача зависимостей: навигация обёрнута в провайдер реестра контейнеров, который хранит их по ключам маршрутов и отдаёт текущий через React Context.
- Доступ из UI: компоненты используют HOC `withContainer` или хуки `useDependency` / `useOptionalDependency`, чтобы получать сервисы из активного контейнера.

## Жизненный цикл

- Корневой контейнер живёт на время сессии приложения.
- Контейнеры, привязанные к маршрутам, создаются при монтировании экрана и удаляются при его размонтировании; при отсутствии локального контейнера используется родительский.

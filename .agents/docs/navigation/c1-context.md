# Контекст: navigation

## Цель

- Дать единый каркас навигации для мобильного клиента, чтобы экраны подключались к стеку без дополнительной обвязки.
- Сохранить связь между маршрутами через источник перехода, чтобы последовательно наследовать контекст и зависимости.

## Границы

- Охватывает навигацию React Navigation в приложении: конфигурацию стека, проброс контекста экрана и ключей маршрутов.
- Не описывает конкретные маршруты фич, deeplink-и, анимации переходов и настройки платформенных навигаторов.

## Внешние интеграции

- Базируется на `@react-navigation/native` и `@react-navigation/native-stack` для построения стека экранов.
- Использует `react-navigation-trail` для добавления идентификатора источника в переходы и извлечения его на целевом экране.
- Связан с `di-react-native`: ключи маршрутов и источник перехода помогают подобрать родительский контейнер зависимостей.

## Ожидания по качеству

- Детерминированные маршруты: статическая конфигурация стека без динамической перерегистрации компонентов.
- Предсказуемая цепочка источников: каждый переход несёт ключ родительского экрана, позволяя восстановить контекст.
- Чёткое разграничение уровней: навигационная обвязка не смешивается с бизнес-логикой фич и управляется корнем приложения.

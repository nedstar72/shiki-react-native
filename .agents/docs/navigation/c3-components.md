# Ключевые компоненты

## Статическая конфигурация стека

- `src/app/index.tsx` формирует Native Stack и оборачивает его в статическую навигацию, чтобы стек и опции экранов задавались единообразно.
- Корневой компонент `App` размещает навигацию внутри провайдера контейнеров, передавая ключи маршрутов в ди-инфраструктуру.

## Следы переходов

- Хук `useTrailNavigation` добавляет `@react-navigation-trail/source` во все поддерживаемые вызовы навигации, включая вложенные actions.
- Функция `extractSource` используется на стороне приёмника (например, в провайдерах контейнера), чтобы определить родительский маршрут и восстановить цепочку контекста.

## Интеграция с DI

- `ContainerRegistryProvider` хранит корневой и экранные контейнеры, связывая их с ключами маршрутов.
- `ContainerProvider` и `useContainer` создают или находят контейнер для текущего экрана, опираясь на источник перехода и состояние навигации, чтобы не терять связи между вложенными экранами.

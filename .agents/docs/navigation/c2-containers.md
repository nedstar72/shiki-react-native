# Контейнеры и потоки

## Навигационное дерево

- Корневой стек описан статически через `createNativeStackNavigator` и `createStaticNavigation` в `src/app/index.tsx`.
- Базовый набор экранов: Welcome/Main как стартовая точка, Auth для входа, AnimeList для каталога.

## Потоки переходов

- Экраны используют `useTrailNavigation`, который оборачивает navigate/push/replace/dispatch и добавляет в параметры ключ текущего маршрута.
- `extractSource` читает этот ключ на целевом экране, что позволяет ди-контейнерам восстановить родителя даже при вложенных действиях навигации.

## Жизненный цикл

- Навигационное дерево обёрнуто в `ContainerRegistryProvider`, регистрирующий контейнеры по ключам маршрутов и очищающий их при размонтировании экранов.
- При создании экрана контейнер берётся из реестра или вычисляется через `resolveParentContainer`, используя источник перехода и состояние стека.

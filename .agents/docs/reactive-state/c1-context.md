# Контекст: reactive-state

## Цель

- Дать единый шаблон для ViewModel с прозрачным жизненным циклом и управлением состоянием в UI-слое.
- Обеспечить реактивное взаимодействие между состоянием (MobX) и потоками действий/эффектов (RxJS) без жёсткой привязки к компонентам.

## Границы

- Охватывает только ViewModel и вспомогательные билдеры редьюсеров/эффектов, которые работают в связке с DI и React-компонентами.
- Не описывает бизнес-логику фич и не заменяет сети/хранилища; остаётся на уровне презентационной модели.

## Внешние интеграции

- Использует MobX для хранения и реактивного чтения состояния ViewModel.
- Использует RxJS для потоков действий и побочных эффектов.
- Интегрируется с DI-слоем (`di-engine`, `di-react-native`) и хуками React (`useViewModel`, `useDisposable`).

## Ожидания по качеству

- Прозрачный жизненный цикл: ViewModel создаётся DI-контейнером и освобождается вместе с компонентом.
- Предсказуемые обновления: состояние мутируется строго в редьюсерах; побочные эффекты оформлены через RxJS-пайплайны.
- Отделение UI: компоненты получают готовое состояние и методы ViewModel, не управляют потоками напрямую.

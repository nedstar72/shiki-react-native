# Ключевые компоненты

## Базовый класс ViewModel

- `ViewModel<S, A>` хранит состояние как MobX-observable и выдаёт поток `state$` для подписок.
- Принимает `initialState`, создаёт поток действий `action$` и маршрутизирует их через редьюсеры.
- Предоставляет `dispatch` для отправки действий и `select` для выборочных реакций на часть состояния.

## ReducerBuilder

- `ReducerBuilder` собирает карту редьюсеров по имени действия.
- Редьюсеры мутируют MobX-состояние внутри `runInAction`, запускаемые при поступлении действия.
- Контракт: редьюсеры не содержат побочных эффектов и работают быстро, чтобы обновлять UI.

## EffectsBuilder

- `EffectsBuilder` регистрирует RxJS-пайплайны, которые реагируют на действия или внешние observable.
- Эффекты подписываются при создании ViewModel и отписываются при dispose.
- Результатом эффекта обычно являются новые действия, публикуемые в `dispatch$`.

## Поток действий

- Действие формируется `createAction(type, payload)` и отправляется через `dispatch`.
- `ViewModel` ищет редьюсер по `type`, передаёт ему состояние и payload; если редьюсера нет, действие игнорируется.
- Эффекты получают типизированные потоки `actionOf(type)` для реакций на конкретные события.

## Интеграция с DI и жизненным циклом

- `useViewModel` достаёт ViewModel из DI-контейнера и оборачивает в `useDisposable`, чтобы dispose вызывался при размонтировании компонента.
- Контейнеры экранов предоставляют ViewModel через `@provide`, сохраняя область жизни экрана.
- Компоненты используют MobX `observer`, чтобы автоматически реагировать на изменения состояния ViewModel.
